How to join

  1. 1

    Open it

    Right-click the zip, pick Extract All, then run freesmlauncher.exe from the folder.

    Windows might say it protected your PC. Click More info, then Run anyway.

    Open the .dmg, drag the app into Applications and launch it.

    macOS blocks it the first time because it isn't signed. Close the warning, open System Settings → Privacy & Security, scroll down and click Open Anyway once.

    Extract the tarball and run ./ph-mc inside it.

    Run the command above. First run sets everything up, after that it just launches.

  2. 2

    Sign in

    The launcher asks for an account the first time, you can sign in with your Microsoft account that owns Minecraft: Java Edition. Alternatively, you can choose Offline Mode and join the server, but for legal reasons™, we strongly advise against it.

  3. 3

    Press Play

    The first launch pulls down all the mods, so give it a few minutes.

Before you ask

I don't own Java Edition
You can press Offline Mode in the launcher and choose any nickname you want, and your data will be saved under that nickname.
My laptop is a potato
You can play the game with only 4GB of RAM allocated! Right-click the instance in Freesm Launcher, then Edit → Settings → Java → Maximum memory allocation.
Can I use my own launcher?
Yes, the address is phack.sh, but you need the exact same mods and versions or the server turns you away.
How does voice chat work?
Press V in game to pick your mic and people nearby will hear you.
